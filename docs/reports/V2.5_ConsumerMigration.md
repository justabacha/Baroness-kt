# Baroness V2.5 — Consumer Migration Report

## 1. Overview & Scope
Phase V2.5 completes the surgical consumer migration based on the pre-V2.5 audit and architectural guidelines:
- **ChatList**: Migrated from hardcoded `#0F0F12` to `MaterialTheme.colorScheme.background` (no wallpaper).
- **ProfileSetup**: Updated main screen background container to `MaterialTheme.colorScheme.background` (no wallpaper), while preserving setup visuals (`image_45` background asset) and local persona setup styling.
- **Wishlist**: Migrated from hardcoded `R.drawable.image_15` asset to `DynamicBackground(activeWallpaperId = activeWallpaperId, dimmed = false)` driven by authoritative `SettingsViewModel`.
- **Wishlist Accent**: Migrated hardcoded app accent bypasses (`#FF4D6D` / `#ff4d6d`) in status indicators and progress bars to `MaterialTheme.colorScheme.primary`.
- **SettingsViewModel Wiring**: Wired `settingsViewModel` into `WishlistScreen` via `AppNavigation` in `MainActivity.kt`.

## 3. Detailed Changes Implemented

### A. ChatList (`ChatListScreen.kt`)
- Replaced `background(Color(0xFF0F0F12))` with `background(MaterialTheme.colorScheme.background)`.
- ChatList now obeys dynamic M3 theme color schemes and global typography, intentionally using clean Material background without `DynamicBackground`.

### B. ProfileSetup (`ProfileSetupScreen.kt`)
- Added `background(MaterialTheme.colorScheme.background)` to root container `Box`.
- Preserved setup visuals (`image_45` image overlay, local persona setup layout, and logout confirmation dialog styling).
- ProfileSetup intentionally avoids wallpaper rendering.

### C. Wishlist (`WishlistScreen.kt` & `MainActivity.kt`)
- Updated `WishlistScreen` signature to accept `settingsViewModel: SettingsViewModel? = null`.
- Passed `settingsViewModel = settingsViewModel` to `WishlistScreen` in `AppNavigation` (`MainActivity.kt`).
- Removed static `BACKGROUND_IMAGE = R.drawable.image_15`.
- Rendered `DynamicBackground(activeWallpaperId = activeWallpaperId, dimmed = false)` using `activeWallpaper` StateFlow.
- Replaced hardcoded `Color(0xFFff4d6d)` in `CircularProgressIndicator` with `MaterialTheme.colorScheme.primary`.

### D. Wishlist Components (`WishItem.kt`)
- Replaced hardcoded `Color(0xFFff4d6d)` in `!! DUSTED` status label with `MaterialTheme.colorScheme.primary`.
- Preserved semantic destructive action button colors in `ConfirmModal.kt`.
